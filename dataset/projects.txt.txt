Project 2

Project Name:
Islamic RAG on Islamic Large Language Models: From Knowledge Acquisition to Trustworthy and Hallucination-Resistant AI

Description:
This project focuses on developing a Retrieval-Augmented Generation (RAG) system for Islamic knowledge. The system is designed to retrieve relevant information from a knowledge base and use the retrieved information to generate contextual responses.

The project focuses on improving the reliability of AI-generated responses by grounding responses in retrieved Islamic knowledge. It aims to reduce hallucinations and provide responses based on relevant information available in the underlying knowledge base.

Development Context:
This project was developed independently after my internship, during my free time, as a personal project to explore Retrieval-Augmented Generation, Large Language Models, and trustworthy AI.

Technologies Used:

* Python
* FastAPI
* React
* TypeScript
* HTML
* CSS

* Personal Project
* Retrieval-Augmented Generation (RAG)
* Large Language Models (LLMs)
